Deep Learning for Fashion Image Classification

Jan 2023 – Mar 2023 · Tecnológico de Monterrey

1. Project Scope

Supervised image classification of clothing items from Fashion MNIST using a CNN and a Fully Connected Feedforward Network. Goal: compare performance across accuracy, generalization, and computational efficiency.

2. CNN Architecture and Training

Implemented with TensorFlow Keras. Architecture: conv layers (ReLU), max pooling, dropout, dense output (softmax). Trained 100 epochs with Adam optimizer and learning rate scheduler. Final test accuracy: 92.1%.

3. Feedforward Network ("TrendyNet")

Multiple dense layers with ReLU activations and dropout. Faster to train (3m 39s vs 10m 42s) but lower accuracy at 87.8% with higher validation variance.

4. Key Takeaways

CNN consistently outperforms on complex classes. Project reinforced: architecture selection, regularization with dropout/L2, data normalization, and learning rate scheduling.

NLP Classifier for Industrial Fault Reports — Ternium

Jan 2023 – Aug 2023 · Tecnológico de Monterrey

1. Project Scope

Automated classification of industrial maintenance records by applying supervised ML to unstructured text. Objective: generate structured labels ("Symptom" and "Cause") from Ternium's fault report database.

2. Data Preparation

Raw dataset of 64,000+ entries cleaned and standardized: lowercase conversion, accent/punctuation removal, stopword elimination (NLTK), and duplicate removal. Key fields tokenized for feature extraction.

3. Model Pipeline

TF-IDF vectorization + Scikit-learn pipelines with Random Forest, Naive Bayes, KNN, SVM, Logistic Regression. Hyperparameters optimized with GridSearchCV.

4. Results and Impact

Random Forest yielded highest accuracy at 61%. Enables faster interpretation of failure reports, reduces manual labeling, and supports preventive maintenance planning. Aligned with SDG 9 and SDG 12.
